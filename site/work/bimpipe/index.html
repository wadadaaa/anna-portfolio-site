/ 01 Context

BIMPipe is a product I design and build on my own, since 2024. It's a web-first tool for MEP engineers doing sanitary and drainage planning: drop in an architect's IFC model, explore it in 2D and 3D, let it detect every toilet and kitchen, place vertical risers, and hand a clean IFC back to Revit. It runs in the browser end to end: the model is parsed locally and never leaves the tab.

/ 02 The problem

An architect's IFC holds every wall, slab and piece of furniture across many storeys, with the fixtures that matter buried among them. Risers have to sit next to those fixtures and line up vertically through every floor they span, and the result has to go back into the BIM pipeline as a file that Revit, ArchiCAD or any IFC-aware tool can open.

/ 04 Key decisions

  1. 01

    In the browser, end to end

    No server upload, no sign-up, no queue. The IFC is parsed with web-ifc inside the tab, so a model never leaves the engineer’s machine.

  2. 02

    Manual override always wins

    Risers are suggested automatically, one per fixture, but a pin you drag yourself survives every re-suggest.

  3. 03

    Vertical alignment by default

    A riser at one point on one floor implies the same shaft on every floor it spans, and the same input always gives the same placement.

/ 05 Outcome

  • Live at bimpipe.com and still in active development: designed and built solo, with an agentic workflow (Claude Code, MCP) from architecture to tests.
  • Handles IFC models up to 500 MB and 64 storeys, parsed locally, and exports an enriched IFC that opens in Revit, ArchiCAD or any IFC-aware tool.
